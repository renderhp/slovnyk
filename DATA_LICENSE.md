# Dictionary data license

The dictionary databases published in this repository's releases contain content from
[Wiktionary](https://www.wiktionary.org), written by Wiktionary contributors, and extracted with
[Wiktextract](https://github.com/tatuylonen/wiktextract) ([kaikki.org](https://kaikki.org)).

The content has been modified: it is filtered, restructured and converted to SQLite.

The databases are licensed under the
[Creative Commons Attribution-ShareAlike 4.0 International License](https://creativecommons.org/licenses/by-sa/4.0/).

Pronunciation audio is not included. It is linked from Wikimedia Commons, where each file has its own license.
